FAQ

Preguntas frecuentes

¿Qué temperaturas debo registrar en el APPCC?

Las de los puntos críticos de cada instalación: cámaras frigoríficas, congeladores, salas de elaboración y transporte. El sistema se configura con los límites de cada área y registra la temperatura de forma continua, cada pocos minutos.

¿Cómo se generan los informes para la inspección?

Automáticamente, en PDF, con fecha, hora y valor de cada registro. Incluyen sello de tiempo (NTP) y firma electrónica PAdES, listos para presentar ante auditorías APPCC/SGSA.

¿Qué pasa si una cámara supera la temperatura límite?

El sistema envía una alerta inmediata por email, SMS o Telegram y queda registrada la incidencia con su duración, para aplicar las acciones correctoras del plan APPCC.

¿Puedo consultar los datos desde el móvil?

Sí. La plataforma PiTemp 2.0 permite ver todas las cámaras desde un mismo panel, accesible desde PC, tablet o móvil.
